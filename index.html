01 / 學習動機

為什麼我們需要微積分？

國高中學的代數與幾何擅長處理「固定不變」的世界，但真實世界無時無刻都在「變化」與「彎曲」。

傳統數學（Static Math） 📐

處理「均勻、筆直、靜止」的問題

🚗 速度問題：只能算「平均速度」

開車 2 小時跑了 120 公里，平均時速是 60 km/h。但這無法告訴你「第 37 分鐘那一瞬間」儀表板指針指在哪裡。

🟦 面積問題：只能算「規則多邊形」

長方形面積 = 長 × 寬，三角形 = 底 × 高 ÷ 2。一旦遇到邊界不斷彎曲的湖泊或拋物線，傳統公式就束手無策。

⚠️ 痛點：面對「連續變化」與「曲線」時缺乏精準工具。
微積分（Calculus） 🚀

駕馭「瞬息萬變、彎曲累積」的世界

⚡ 微分（Differentiation）：把時間切到極短

把時間間隔縮短到趨近於 0，算出「這一瞬間的瞬時速度」與曲線在某一點的傾斜程度（切線斜率）。

🧩 積分（Integration）：把圖形切到極細再相加

把不規則曲線切成無數個極細長方形，全部加起來，就能精準算出任意曲線下方的面積與累積總量。

✨ 核心精神：「以直代曲、化整為零、積零為整」。
02 / 微積分的地基

極限（Limit）：無限逼近，但永遠不碰觸

想知道拋物線 f(x) = x² 在 x = 2 這一點有多陡？我們先找附近一點 x = 2 + Δx 連成「割線」，再讓距離 Δx 無限縮小！

函數曲線 f(x)=x² 動態割線（連接 P 與 Q） 真實切線（斜率 = 4）
Δx = 1.000
← 越靠近 0 (Δx = 0.001) 距離較遠 (Δx = 1.0) →
割線斜率公式：
斜率 =
f(2 + Δx) − f(2) Δx
= 4 + Δx
目前割線斜率： 5.000
極限目標（切線斜率）： 4.000
💡 試著把滑桿往左拖動，讓 Δx 越來越接近 0，觀察橘色割線如何與綠色切線重合！
03 / 微觀切分

微分（Differentiation）：捕捉「這一瞬間」的變化率

當剛才的 Δx 縮到極限（趨近於 0）時，割線斜率就正式成為「導數（Derivative）」！

🔬
導數的數學定義
將微小變化量取極限，記作 f'(x) 或 dy/dx
f'(x) =
lim Δx→0
f(x + Δx) − f(x) Δx
dy/dx

1. 看懂神秘符號

萊布尼茲發明的符號 dy / dx 其實非常直白：

  • • dx：代表 x 的極微小變化量
  • • dy：代表隨之產生的 y 極微小變化量
  • • 兩者相除，就是「變化敏感度」！
📈

2. 幾何意義：切線斜率

想像你在雲霄飛車軌道上滑行，車頭手電筒照出去的直線方向就是「切線」：

  • • f'(x) > 0：正在爬坡（函數遞增）
  • • f'(x) < 0：正在下坡（函數遞減）
  • • f'(x) = 0：到達山頂最高點或谷底最低點！
🏎️

3. 真實世界的應用

只要牽涉到「變化率」與「尋找最佳極值」，背後全都是微分：

  • • 汽車時速表：位置對時間微分 = 瞬時速度
  • • 商業利潤最大化：找到斜率為 0 的最高獲利點
  • • AI 深度學習：梯度下降法靠微分尋找誤差最低點
04 / 宏觀累積

積分（Integration）：把無數個「極小」累積起來

如何求曲線 f(x) = x² 從 x = 0 到 x = 3 下方的面積？把它切成 n 個長方形加起來！

黎曼矩形（中點法逼近） 區間：x ∈ [0, 3]
n = 4 塊
粗糙切割 (n = 4) 極細切割 (n = 100) →
定積分符號表達： ∫₀³ x² dx
目前矩形總面積： 8.9531
真實精確面積： 9.0000
誤差百分比： 0.52%
💡 拉長長方形符號 ∫ 其實就是英文字母 S (Sum，總和) 的拉長版！當 n → ∞ 時，矩形階梯就會平滑貼合曲線。
05 / 偉大的統一

微積分基本定理：原來微分與積分是互逆的！

牛頓與萊布尼茲發現了人類數學史上最美妙的橋樑：看似無關的「求切線」與「求面積」，其實就像加法與減法、乘法與除法一樣互為逆運算！

💡 為什麼這件事這麼重要？
因為我們不需要真的去切一億個長方形來算面積！只要找到「誰微分之後會變成 f(x)」（反導函數 F(x)），把頭尾相減就能瞬間算出精確積分！
